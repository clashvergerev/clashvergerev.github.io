第二章：从零开始的安装与配置

2.1 获取正版应用

目前Shadowrocket S仅支持iOS平台，用户需通过App Store获取。值得注意的是：

  • 部分地区可能需要切换Apple ID地区才能搜索到

  • 安装前确保设备剩余存储空间不少于50MB

2.2 基础配置四步曲

步骤一：添加服务器配置
点击主界面右上角的"+"按钮，选择对应的协议类型。对于新手用户，建议从Shadowsocks开始尝试。

步骤二：填写服务器参数
包括：
- 服务器地址（通常为域名或IP）
- 端口号（常见如443、8388等）
- 加密方式（推荐选择AEAD加密算法）
- 密码（区分大小写，需准确输入）

步骤三：测试连接
保存配置后，轻点服务器条目进行连通性测试。绿色指示灯表示连接成功。

步骤四：启用代理
滑动顶部开关即可开启全局代理，或通过规则实现智能分流。

2.3 高级配置指南

对于进阶用户，以下设置可以显著提升使用体验：

自定义规则系统
通过"规则"选项卡，您可以：
- 设置特定域名强制走代理（如*.google.com）
- 指定国内流量直连（提升访问速度）
- 创建复杂的正则表达式规则

DNS优化配置
建议将DNS设置为：
- 国内：223.5.5.5（阿里DNS）
- 国外：1.1.1.1（Cloudflare）
可有效防止DNS污染并提升解析速度。

MTU调优
在高级设置中，将MTU值调整为1400-1450区间，可改善某些网络环境下的传输稳定性。

3.1 提升速度的五个秘诀

  1. 选择物理距离近的节点：延迟通常与物理距离成正比
  2. 避开网络高峰期：国际出口带宽在晚间通常较为拥堵

  4. 启用压缩传输：在支持的服务端配置中开启压缩选项
  5. 定期更新客户端：新版本往往包含性能优化

3.2 常见问题解决方案

问题一：连接成功但无法上网
排查步骤：
1. 检查设备系统时间是否准确（误差需在2分钟内）
2. 尝试切换不同的DNS服务器
3. 关闭WiFi助理等可能干扰连接的系统功能

问题二：频繁断线
可能原因及对策：
- 服务器负载过高 → 更换节点或联系服务商
- 本地网络不稳定 → 切换网络环境测试
- 协议特征被识别 → 尝试启用TLS或WebSocket传输

问题三：耗电量异常
优化建议：
- 关闭不必要的后台刷新
- 降低心跳间隔（不建议低于300秒）
- 避免同时开启多个代理应用

FAQ

PassWall2 在路由器上使用 TUN 模式会有什么影响？
启用 TUN 模式会拦截并转发路由器上全部或选定流量，这会增加路由器 CPU 与内存负担，可能影响路由器其他服务表现。建议在性能足够的设备上启用，或仅对特定设备/端口进行分流。
Nekobox 能否使用订阅链接？
Nekobox 支持通过订阅 URL 导入节点。用户在应用中选择“添加订阅”，输入链接后系统会自动更新节点数据，并支持定期刷新，确保始终使用最新线路。
Netch 如何区分全局代理和规则代理？
全局代理会将所有流量通过节点转发，而规则代理仅对指定 IP、端口或应用生效。用户可根据需求选择代理模式，实现流量优化和不同应用的最佳网络体验。
Sing-box 如何实现精确域名分流？
Sing-box 可以按域名设置分流规则，将不同流量发送到指定节点。结合策略组使用，可实现网页、视频和游戏流量精准分配，提高访问速度和网络稳定性。
Trojan 的伪装域名如何选择更安全？
伪装域名应选择真实可访问的网站，且证书有效。这样 Trojan 流量能伪装成正常 HTTPS 请求，减少被封锁或检测的风险，提高节点安全性和稳定性。
Matsuri 的节点自动测速功能如何配置？
Matsuri 可以设置测速周期和节点列表，程序会自动测试延迟和速度并排序。用户可根据测试结果选择最佳节点，提高网络访问速度和使用体验。
V2Ray 的路由规则如何实现按应用分流？
V2Ray 支持按用户标签或端口匹配应用流量，结合策略组可实现指定应用走特定节点。这样可以保证游戏、视频和浏览器流量各自走最优线路，提高访问效率。
Mihomo 节点分类管理有什么作用？
节点分类可按地区、延迟或用途分组，结合策略组实现自动分流。方便管理大量节点，快速选择最优节点，提高访问速度和连接稳定性，优化网络管理效率。
Mellow TUN 模式如何拦截全局流量？
TUN 模式会拦截系统 IP 层的所有流量，实现全局代理。相比 SOCKS5 只影响部分应用，TUN 可以覆盖游戏、视频和浏览器等所有流量，提高科学上网体验的全面性。
Surfboard 是否支持应用分流？
支持。Surfboard 可通过策略组和规则文件将不同应用流量分配到指定节点，保证游戏、视频和浏览器流量走最优节点，提高访问速度和网络稳定性。
