高频问题深度解析（FAQ）

1. 科学上网是否触碰法律红线？ 这是一个无法一概而论的问题。在中国大陆，未经许可的“翻墙”行为违反了《计算机信息网络国际联网管理暂行规定》。但在香港、台湾地区以及海外多数国家，使用VPN是合法的。即便在允许使用的国家，利用该技术实施网络攻击或传播违法内容同样构成犯罪。核心提醒： 请务必了解您所在地区的法律后果，并自行承担相应风险。

2. 为何我的连接速度很慢？ 速度瓶颈通常源于以下几点：一是物理距离，跨国传输必经海底光缆，延迟无法避免；二是所选节点在高峰时段拥堵；三是本地网络运营商对VPN流量进行了干扰。解决方案包括：更换至空闲节点、尝试切换代理协议（如从TCP改为UDP）、或在深夜非高峰时段测试。

3. 工具提示“连接已断开”或“超时”怎么办？ 请按以下顺序排查： - 检查本地网络是否正常（能否访问国内网站）。 - 确认服务器订阅链接是否过期（官网续费后需重新更新订阅）。 - 尝试更换端口（如从443改为8443）。 - 检查系统时间是否准确（时间偏差过大会导致TLS握手失败）。 - 若以上均无效，卸载客户端并重启设备，重新安装最新版本。

4. 手机端和电脑端可以同时登录吗？ 这取决于您的套餐类型。部分服务商允许1-3台设备同时在线，部分则按设备数计费。请查阅官网服务条款，避免因多设备登录导致账号被临时封禁。

5. 如何保障使用过程中的隐私安全？ 除了选择不记录日志的服务商外，您还应启用客户端的“全局模式”或“严格路由”，确保所有DNS请求均通过代理隧道加密传输。同时，避免在科学上网状态下登录涉及资金交易的敏感账号，以防中间人攻击。

FAQ

PassWall2 在路由器上使用 TUN 模式会有什么影响？
启用 TUN 模式会拦截并转发路由器上全部或选定流量，这会增加路由器 CPU 与内存负担，可能影响路由器其他服务表现。建议在性能足够的设备上启用，或仅对特定设备/端口进行分流。
Hiddify Next 订阅更新后节点消失，如何恢复？
先检查订阅源是否更改格式或被下架，尝试重新粘贴订阅链接并手动刷新；若仍缺失，联系订阅提供方确认是否停用某些节点或使用了新的访问权限机制（例如 token 验证）。
Sing-box 的自定义 outbound 功能有什么用？
Sing-box 允许用户自定义多个 outbound 出口，并通过路由规则选择性输出。例如可让流媒体走特定节点，而其他网站使用备用节点，从而实现精准分流。
QuantumultX 支持哪些类型的分流规则？
QuantumultX 支持域名、IP、端口、协议和用户自定义脚本分流。结合策略组使用，可实现精准流量控制，如广告屏蔽、视频加速和游戏优化，提高访问速度和体验。
VMess 与 Shadowsocks 哪个更安全？
VMess 使用动态认证机制，防止重放攻击，而 Shadowsocks 依赖静态密钥。总体来说，VMess 的安全性更强，尤其在应对 DPI 检测和中间人攻击时表现更优。
Nekobox 是否支持自定义 DNS 解析？
支持。用户可以在配置中指定 DNS 服务器或启用 DoH/DoT 功能，确保域名解析安全和快速，避免本地 DNS 污染或被劫持。
Sing-box 的域名规则如何实现分流？
Sing-box 支持按域名匹配流量，将不同网站或应用流量分配到指定节点。结合策略组自动切换低延迟节点，可优化访问速度，保证网络稳定性并提高整体体验。
Clash 的策略组如何提升分流效率？
策略组可以将多个节点或规则组合在一起，实现按条件自动选择最佳节点。通过策略组，用户无需手动切换节点即可根据延迟、地理位置或流量类型自动分流，提高网络效率。
V2Ray 如何使用 WebSocket 传输？
在 V2Ray 配置文件中将传输方式设置为 ws，即启用 WebSocket 模式。结合 CDN 和 TLS，可实现安全高速的代理链路。WebSocket 常用于伪装成 HTTPS 流量，从而降低被识别风险。
VLESS + XTLS 在移动网络的优势？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定的移动网络。结合策略组和多节点切换，可提升网页浏览、视频播放和游戏的连接稳定性和流畅度。
